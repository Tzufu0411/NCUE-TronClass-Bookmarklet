# NCUE TronClass Bookmarklet

一個用於 TronClass 的「瀏覽器書籤工具」。

> 原型為雲科某位資管學長製作的，啊我也不知道是誰，我從我雲科認識的人拿到的，然後我就把漏洞修一修，把程式適配為彰師可用，欸不過好像理論上這每校 TronClass 應該都能用，因為我把網域檢查刪掉了，但我沒試，idk

## 使用方式

### 1. 開啟書籤管理員

點擊瀏覽器右上角的 **⋮** → **書籤和清單** → **書籤管理員**。

<br>

<img width="897" height="680" alt="開啟書籤管理員" src="https://github.com/user-attachments/assets/835485a3-6aab-40c8-9f10-a06ca34b7843" />

### 2. 新增書籤

在右上角點擊 **⋮** → **新增書籤**。

<br>

<img width="246" height="453" alt="新增書籤" src="https://github.com/user-attachments/assets/e2b5359f-4125-4377-9156-622fdfb44478" />

### 3. 複製程式碼

複製我這個 repo 裡面的 [main.js](https://github.com/Tzufu0411/NCUE-TronClass-Bookmarklet/blob/main/main.js)。

<br>

<img width="827" height="443" alt="複製程式碼" src="https://github.com/user-attachments/assets/26eb5858-26cd-4007-9dc5-6da8e6b05a80" />

將程式碼貼到書籤的 **網址** 欄位並儲存。

### 4. 在 TronClass 使用

進入 TronClass 的課程頁面。

在 `content#` 頁面可以一次處理全部課程。

<img width="125" height="42" alt="content 頁面" src="https://github.com/user-attachments/assets/88c294e9-ea7b-464e-b338-e3300830c7d2" />
<br>

點擊任意一個課程後，在 `learning-activity` 頁面可以單獨處理該課程。
<br>
<img width="312" height="47" alt="learning-activity 頁面" src="https://github.com/user-attachments/assets/7733a72c-4e0d-4a93-a5a4-cc751d3199c0" />

接著點擊瀏覽器右上角的 **⋮** → **書籤和清單** → **書籤**，再點擊剛剛建立的書籤。

<img width="596" height="73" alt="使用書籤工具" src="https://github.com/user-attachments/assets/95be8d70-d277-42d5-94b2-b61158649fa3"/>

如果你的書籤會顯示在瀏覽器上方的書籤列，也可以直接點擊，反正我是不會啦，我忘記這哪邊可以設定。

---

## 注意事項

本工具會操作 TronClass 頁面上的課程資料與相關功能，使用前請確認自己了解程式的作用。
